# Codex Usage Floating

原生 macOS 菜单栏应用。沙漏图标右侧显示可选择的 5 小时或一周剩余用量；悬停预览，点击固定。

用量会自动更新：启动时立即读取，Codex 推送新用量时即时同步，并每分钟自动复查一次。

5 小时窗口显示一条剩余用量进度条；一周窗口显示两条：剩余用量和本刷新周期剩余时间。

悬停面板为紧凑布局，所有进度条均为蓝色；点击菜单栏图标后，面板锚定在菜单栏正下方展开。

应用检测到桌面版 Codex 正在运行时会显示一个可拖动的悬浮球；关闭 Codex 后悬浮球自动隐藏。悬浮球始终位于普通窗口上方，并会记住拖动后的位置。

打开“5小时用量恢复后发送提醒”后，应用在检测到 5 小时限额进入新周期时会发送 macOS 本地通知；首次开启仅记录当前周期，不会立即提醒。面板中的“手动刷新”会立即请求一次最新用量。

悬浮球静止时显示所选窗口（5 小时或一周）的剩余百分比；鼠标移入后会展开为圆角信息面板，展示全部用量、刷新时间和设置。可在展开面板中切换悬浮球显示 5 小时或一周数据。

请只解压并打开 `Dist/CodexUsageMenu.app.zip` 中的 App。它是菜单栏应用，启动后不会出现 Dock 图标或普通窗口；请在屏幕右上角寻找沙漏和 `5h --`，数据加载后会显示百分比。

源码可直接在 Xcode 中打开 `Package.swift`。
